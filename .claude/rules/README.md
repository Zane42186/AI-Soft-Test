# 项目规则目录

将主题域规则文件放在此目录下。规则文件会在匹配的文件路径或操作上下文下自动加载。

## 规则文件格式

每个规则文件是一个 `.md` 文件，包含：

```yaml
---
description: 规则简述
paths: "**/*.ts"        # 可选：限定规则生效的文件范围
---
```

## 示例规则

### 代码审查规则 (`code-review.md`)
- 所有 PR 必须经过 Claude Code 审查
- 审查通过后方可合并

### 测试规则 (`testing.md`)
- 新功能必须包含测试
- 测试覆盖率不低于 80%

### 文档规则 (`documentation.md`)
- 所有公开 API 必须有中文文档
- 复杂算法需附带注释说明
