## 教学文档内部格式约定

### 天数标题

```
# 第X天：{天数主题}
```

### 元数据行（第一天标题下方）

```
> 学习日期：第X天 | 模块：{模块名} | 建议学习时长：X-X 小时
```

### 练习区

```
## 课后练习

### 练习一：{练习主题}
...

### 练习二：{练习主题}
...
```

### 自检清单

```
## 自检清单

- [ ] 知识点一
- [ ] 知识点二
```

## 其他约定

### 文件编码

所有 Markdown 文件使用 **UTF-8 without BOM** 编码。

### 文件换行

使用 **CRLF** 换行（Windows 环境）。

### 特殊文件

| 文件 | 用途 | 是否提交 Git |
|------|------|-------------|
| `.gitignore` | Git 忽略规则 | 是 |
| `.mcp.json` | MCP 服务器配置 | 是 |
| `*.local.*` | 本地个人配置 | 否（gitignored） |
| `Conclusion/*.md` | 对话总结归档 | 是 |
| `Conclusion/.summary_record.json` | 总结状态 | 是 |
